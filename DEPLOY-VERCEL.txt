CHE PLANETA — ACTUALIZACIÓN DEL ESCÁNER

1. Subí el contenido de esta carpeta al MISMO repositorio de GitHub conectado a tu proyecto Vercel.
2. En Vercel > Settings > Environment Variables, configurá GEMINI_API_KEY con tu clave privada de Google AI Studio. No la subas a GitHub ni la compartas.
3. La variable debe estar habilitada para Production, Preview y Development.
4. Guardá y hacé Redeploy si cambiaste variables. Los commits nuevos en GitHub despliegan automáticamente.
5. El modelo predeterminado es gemini-2.5-flash. Opcionalmente podés definir GEMINI_MODEL en Vercel para cambiarlo.
