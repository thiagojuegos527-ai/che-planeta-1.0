CHE PLANETA — ACTUALIZACIÓN DEL ESCÁNER

1. Subí el contenido de esta carpeta al MISMO repositorio de GitHub conectado a tu proyecto Vercel.
2. En Vercel > Settings > Environment Variables, configurá GEMINI_API_KEY con tu clave privada de Google AI Studio. No la subas a GitHub ni la compartas.
3. La variable debe estar habilitada para Production, Preview y Development.
4. Guardá y hacé Redeploy si cambiaste variables. Los commits nuevos en GitHub despliegan automáticamente.
5. El modelo predeterminado es gemini-2.5-flash. Opcionalmente podés definir GEMINI_MODEL en Vercel para cambiarlo.

CAMBIOS PRINCIPALES
- La cámara ya no reemplaza una captura fallida por la primera imagen de muestra (botella).
- El análisis visual se enfoca en la foto real y diferencia explícitamente caja de cartón y botella.
- Los errores de IA no se convierten en resultados de ejemplo.
- El servidor Express se exporta para la función serverless de Vercel.
- Se agrega la ruta API catch-all y configuración de Vercel; se corrige __dirname en Vite ESM.
- El filtro de puntos verdes devuelve una lista vacía cuando ningún punto coincide, en vez de sugerir todos los puntos sin relación.

NOTA
Los datos de puntos verdes que ya estaban en el proyecto se conservaron; este paquete no certifica independientemente que sus direcciones, horarios o materiales aceptados estén vigentes. Verificalos con el municipio antes de publicarlos como confirmados.


ACTUALIZACIÓN DEL ESCÁNER SIN GEMINI
- Esta versión usa MobileNet/TensorFlow.js en el navegador. La fotografía se procesa en el dispositivo y no se envía a Gemini.
- La primera vez necesita conexión a Internet para descargar los archivos del modelo desde TensorFlow Hub; luego el navegador puede conservarlos en caché.
- El modelo es generalista, no fue entrenado específicamente para reciclaje. Puede reconocer algunos objetos comunes, pero no siempre distingue el material exacto. Si no tiene suficiente confianza, muestra objeto no identificado en vez de inventar.
- Para desplegar: reemplazar los archivos del repositorio, eliminar el package-lock.json viejo y dejar que Vercel genere uno nuevo con npm install. No hace falta configurar GEMINI_API_KEY para el escáner nuevo.
